#  Weather Dashboard

A responsive and feature-rich Weather Application built using HTML, CSS, and JavaScript. This app connects with a real-time Weather API to provide accurate current conditions and extended forecasts for any city worldwide.

##  Key Features

* ** Search Weather by City:** Instantly fetch weather details for any city globally with a simple search.
* ** Detailed Metrics:** Displays real-time temperature, humidity levels, and wind speed.
* ** 5-Day Forecast:** Shows an extended 5-day weather prediction layout.
* ** Dynamic Weather Icons:** Visual icons change automatically based on the current weather condition (sunny, rainy, cloudy, etc.).
* ** Fully Responsive:** Optimized for both mobile and desktop screens.

##  Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Data Source:** Fetch API (Weather API)

##  How to Run Locally

1. Clone this repository.
2. Open `index.html` in your web browser.
